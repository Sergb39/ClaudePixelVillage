Connect Claude Code

The village is ready for local hook events. Generate a configuration, merge it into your Claude project settings, then start a new session.

  1. Keep this local server running.
  2. In this project directory, run:npm run hooks:generate
  3. Follow the generated setup instructions in README.md. Preserve your existing hooks.

The bridge sends event names and IDs, never your prompts or code. If the village is closed, Claude keeps working normally.
