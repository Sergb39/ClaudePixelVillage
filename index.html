Connect Claude Code

Install the Pixel Village mod once, then watch your local Claude sessions here. Keep this village server running.

  1. In this project directory, run the setup check:npm run setup
  2. Follow the exact marketplace and plugin commands it prints inside a local Claude Code session.
  3. Run /village to check delivery, then submit a prompt to bring an adventurer here.

Setup checks the receiver, token, and Claude CLI, and prepares a local mod package. It does not change Claude settings. Requires terminal Claude Code 2.1.287+ or Desktop Code 2.1.286+. Only event metadata is sent, never your prompts or code.
